DAP Groupware AI Assistant

개인정보처리방침

시행일: 2026년 3월 27일  |  버전: v1.1
DAP Groupware AI Assistant(이하 "확장 프로그램")는 DAP 그룹웨어 사용자의 업무 효율화를 위해 제공되는 사내 전용 Chrome 확장 프로그램입니다. 본 방침은 확장 프로그램이 수집·처리하는 정보와 그 보호 방법을 안내합니다.

1수집하는 정보

확장 프로그램은 아래 정보를 처리합니다.

구분항목수집 목적저장 위치
사용자 설정글자크기, 다크모드 여부, 자주쓰는 문구UI 환경 유지Chrome 로컬 스토리지
대화 이력AI와의 대화 내용 (최근 6쌍)패널 재시작 시 이력 복원Chrome 세션 스토리지
사용 통계기능별 사용 횟수 (브리핑·요약·번역 등)개인 사용 현황 표시Chrome 로컬 스토리지
업무 콘텐츠AI 분석 요청 시 메일·사내통신·결재 본문AI 요약·번역·브리핑 생성사내 프록시 서버 (처리 후 즉시 삭제)

2정보의 이용 목적

  • 메일·사내통신·결재 문서의 요약, 번역, 답장 초안 생성
  • 업무 브리핑 및 일정 자동 등록
  • 사용자 UI 설정 저장 및 복원
  • 개인 사용 통계 표시 (본인에게만 노출)

3정보의 보관 및 파기

항목보관 기간파기 방법
대화 이력브라우저 세션 종료 시 즉시 삭제세션 스토리지 자동 삭제
사용자 설정·통계확장 프로그램 삭제 시 또는 최근 30일로컬 스토리지 자동 삭제
AI 처리용 업무 콘텐츠전송 즉시 (보관하지 않음)사내 프록시 서버에서 응답 후 즉시 삭제

4제3자 제공

확장 프로그램은 사용자의 업무 콘텐츠를 아래 경로로만 전송합니다.

  • 사내 AI 프록시 서버
  • 외부 제3자에게 개인정보를 판매하거나 마케팅 목적으로 제공하지 않습니다.
  • 사내 프록시 서버는 방화벽 내부에 위치하며, 전송 데이터는 응답 생성 후 즉시 삭제됩니다.

⚠️ 기밀 등급 문서 또는 민감한 개인정보가 포함된 문서는 AI 분석 기능 사용 전 정보보호팀과 협의하시기 바랍니다.

5사용자 권리

  • 열람 및 삭제: Chrome 주소창 → chrome://extensions → 확장 프로그램 상세 → "데이터 삭제"로 모든 저장 데이터 삭제 가능
  • 대화 이력 초기화: 패널 상단 🔄 버튼으로 즉시 초기화 가능
  • 확장 프로그램 제거: 브라우저에서 제거 시 모든 로컬 데이터 자동 삭제

6보안 조치

  • API 키 등 인증 정보는 사내 서버 환경변수로만 관리하며 클라이언트에 노출되지 않습니다.
  • 확장 프로그램은 https://gw.dap.co.kr 도메인에서만 동작하도록 제한됩니다.
  • Content Security Policy(CSP)가 적용되어 외부 스크립트 실행이 차단됩니다.
  • 사내 프록시 서버는 허용된 출처(Origin)에서만 요청을 수락합니다.

7방침의 변경

본 개인정보처리방침은 법령·서비스 변경에 따라 수정될 수 있습니다. 변경 시 시행일 기준으로 본 페이지에 게시하며, 중요한 변경은 사내 공지를 통해 안내합니다.
