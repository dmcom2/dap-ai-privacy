개인정보처리방침

시행일: 2026년 10월 28일  |  버전: v1.3 (최초 시행 2026년 7월)
DAP Groupware AI Assistant(이하 "확장 프로그램")는 DAP 그룹웨어 사용자의 업무 효율화를 위해 제공되는 사내 전용 Chrome 확장 프로그램입니다. 본 방침은 확장 프로그램이 수집·처리하는 정보와 그 보호 방법을 안내합니다.

1수집하는 정보

확장 프로그램은 아래 정보를 처리합니다.

2정보의 이용 목적

  • 메일·사내통신·결재 문서의 요약, 번역, 답장 초안 생성
  • 업무 브리핑 및 일정 자동 등록
  • 사용자 UI 설정 저장 및 복원
  • 개인 사용 통계 표시 (본인에게만 노출)
  • 서비스 개선·장애 감지를 위한 익명 사용 통계 집계 (이름·문서 내용 제외, 설정에서 끌 수 있음)
  • 작성 중인 메일·사내통신·기안의 발송 전 점검 (사용자가 [보내기 전 점검]을 누른 경우)

4처리 위탁 및 외부 전송

AI 기능을 실행하면 업무 콘텐츠가 아래 경로로 전송됩니다. 사용자가 AI 기능(브리핑·요약·번역·초안·검색 등)을 직접 실행할 때만 전송되며, 그룹웨어를 단순히 열람하는 것만으로는 전송되지 않습니다.

단계수신자전송 내용목적
1단계사내 AI 프록시 서버 (사내망)AI 요청 내용 전체API 키 보호·요청 중계·첨부 파일 변환
2단계BizRouter (AI API 중계 서비스, 외부)AI 요청 내용 전체AI 모델 호출 중계
3단계OpenAI (기본 모델), Google Gemini (혼잡 시 대체 모델)AI 요청 내용 전체요약·번역·브리핑·초안 생성
  • 외부 제3자에게 개인정보를 판매하거나 마케팅 목적으로 제공하지 않습니다.
  • 서비스 개선과 장애 감지를 위해 기능별 사용 횟수, 답변 평가(도움됨/아쉬움)와 선택한 사유, 오류 발생 종류(예: 그룹웨어 통신 실패)를 사내 프록시 서버에 익명으로 집계합니다. 이름·계정·문서 내용은 보내지 않으며 최근 90일분만 보관합니다. 환경 설정의 "사용 통계 익명 전송"에서 끌 수 있습니다.
  • 첨부파일 요약 기능은 사용자가 버튼을 누른 경우에만 열린 문서의 첨부파일(최대 10개)을 사내 프록시 서버로 보내 글자를 추출한 뒤 AI에 전달하며, 서버의 임시 파일은 즉시 삭제합니다.
  • AI 요청을 보내기 전에 주민·외국인등록번호, 휴대폰 번호, 카드 번호, 계좌 번호, 여권 번호를 자동으로 가립니다(기본 적용, 첨부 파일에서 추출한 글자 포함). 본문 이미지 속 글자와, 서버가 글자를 읽지 못해 원본 그대로 AI에 전달한 PDF 첨부는 가려지지 않습니다.
  • 사내 프록시 서버는 요청 내용을 저장하지 않으며, 응답 생성 후 첨부 임시 파일을 즉시 삭제합니다.
  • 외부 AI 서비스에서의 데이터 보관·학습 활용 여부는 각 제공자의 기업용 API 정책을 따릅니다.

⚠️ 기밀 등급 문서 또는 민감한 개인정보가 포함된 문서는 AI 분석 기능 사용 전 정보보호팀과 협의하시기 바랍니다.

5사용자 권리

  • 열람 및 삭제: Chrome 주소창 → chrome://extensions → 확장 프로그램 상세 → "데이터 삭제"로 모든 저장 데이터 삭제 가능
  • 대화 이력 초기화: 패널 상단 [새 대화] 버튼으로 즉시 초기화 가능
  • 확장 프로그램 제거: 브라우저에서 제거 시 모든 로컬 데이터 자동 삭제

6보안 조치

  • API 키 등 인증 정보는 사내 서버 환경변수로만 관리하며 클라이언트에 노출되지 않습니다.
  • 확장 프로그램은 https://gw.dap.co.kr 도메인에서만 동작하도록 제한됩니다.
  • Content Security Policy(CSP)가 적용되어 외부 스크립트 실행이 차단됩니다.
  • 사내 프록시 서버는 허용된 출처(Origin)와 지정된 확장 프로그램 ID에서만 요청을 수락합니다.
  • AI가 만든 링크는 그룹웨어(gw.dap.co.kr) 주소만 열리도록 제한되며, 에디터에 넣는 AI 생성 HTML은 위험 요소를 제거한 뒤 삽입됩니다.

7방침의 변경

본 개인정보처리방침은 법령·서비스 변경에 따라 수정될 수 있습니다. 변경 시 시행일 기준으로 본 페이지에 게시하며, 중요한 변경은 사내 공지를 통해 안내합니다.
